# 观察者分工

## Quinn
横向巡检。

它负责每天去看：
- 各仓心跳有没有真的新
- cross-repo 台账是不是真
- 上游共享 workflow 有没有漂移
- 其它仓库里的散文有没有因为别人的改动作废

它更像外部审计员：看一圈世界，抓“这边写的和外面已经不是一回事”。

## Devon
纵向兜底。

它不该做 Quinn 的第二个版本。它只负责：
- 备份是不是快过期
- 演练是不是快过期
- heartbeat 有没有过窗
- 承重 agent 的抄本是不是快过期
- 有没有比 Quinn 更硬的证据

它的正确状态不是“每天都说话”，而是：**没有新东西就闭嘴。**

## 为什么要分开
如果两个人都在说“都正常”，第二条消息很快会变成背景噪音。那不是双保险，是双喇叭。

真正的双保险是：
- 一个人看横向世界
- 一个人看纵向兜底
- 两个人都不负责复读对方已经说过的话
