# Known Blind Spots

## Still needs human or external proof
- Skill summary auto-triggering: success/failure can look normal from inside a conversation
- ClickUp UI-only agent fields
- Exact visible tool labels in agent UI
- Prompt prose that became false because another repo changed
- Any live truth that only exists in another repo or another system
- Explanatory comments disappearing while assertions remain green

## Why this file exists
A backup that does not list its own blind spots teaches the next person the wrong lesson: that green means complete.
