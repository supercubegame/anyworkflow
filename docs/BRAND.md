# Brand Note

## 当前 logo
- 文件：`assets/logo-1080.png`
- 用途：仓库首页、仓库头像、文档页头、后续 README 头图的主视觉锚点

## 这版 logo 在表达什么
- 外圈：反馈闭环
- 内侧两条路径：分支汇入同一条工作流
- 中心勾：验证通过 / gate

它不是流程图图标，而是把“闭环 + 汇合 + 验证”压成一个可缩放的品牌记号。

## 使用建议
- 适合浅色底
- 适合在 README 顶部单独出现，不必强行配很多说明字
- 缩到小尺寸时，优先保留完整轮廓，不要再叠别的文字或小标语

## 不要这样用
- 不要拉伸
- 不要换成高饱和杂色
- 不要叠阴影或立体效果
- 不要把它当流程示意图里的节点图标重复使用太多次

## 下一步如果要继续做视觉
- 再做一张 README 顶部 hero 图
- 视觉系统继续沿用：蓝色主循环 + mint 验证内核 + 浅底
